# DevRel Talk Archive

Monthly digests of community-submitted conference talks for the developer
learning team.

Layout:

- `policy/curation_policy.md` - the curation policy.
- `inbox/talk_submissions.json` - the current intake list.
- `digests/` - published talk digests, one `<submission_id>.md` per talk.
- `reports/` - machine-readable curation reports.

Archived transcripts are stored in the companion transcript-cache repository;
each intake record links to its raw transcript when one is available.
