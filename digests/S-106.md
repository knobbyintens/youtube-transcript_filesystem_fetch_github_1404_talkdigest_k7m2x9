## Summary
This talk explores the engineering behind transformer inference engines and fast generation. It walks through the model anatomy, the prompt and decode phases, key-value caching, batching strategies, quantization, and the metrics used to benchmark a serving stack honestly.

## Key takeaways
- Inference has two phases - prompt and decode - that stress hardware differently.
- Key-value caching avoids recomputation but grows memory as sequences get longer.
- Static batching favours throughput while continuous batching favours latency; each introduces tradeoffs.
- Quantization stores weights and activations in lower precision without necessarily destroying quality, and honest benchmarking should report tokens per second and time to first token.
