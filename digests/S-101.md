## Summary
This talk walks through what it takes to move a neural network research prototype into production, covering data pipelines, training strategy, evaluation, and serving. It highlights the practical choices teams face around batch sizes, learning rates, checkpointing, and how offline metrics can diverge from live user behaviour.

## Key takeaways
- A model is only as good as the examples that feed it, so invest early in solid data pipelines.
- Training strategy matters: choose batch sizes carefully, understand how learning rates interact with the schedule, and add checkpointing for long runs.
- Offline evaluation metrics often hide gaps that only appear once a model meets live users, so plan for online monitoring.
- Production serving needs request batching, cached embeddings, drift monitoring, and a fast rollback path when quality drops.
