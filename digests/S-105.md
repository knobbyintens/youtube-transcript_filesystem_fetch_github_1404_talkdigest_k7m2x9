## Summary
This talk presents a repeatable workflow for debugging React applications in the browser. It covers the browser developer tools, the JavaScript console, React rendering and profiling, common frontend pitfalls, and source maps that connect minified stack traces back to the original code.

## Key takeaways
- Use browser developer tools to inspect the component tree, pause on exceptions, and trace failing network requests.
- Reproduce bugs with the smallest possible input and lean on the JavaScript console to iterate quickly.
- Track down unnecessary re-renders with the React profiler, and watch for pitfalls such as stale closures and surprising state batching.
- Enable source maps so minified stack traces point to the exact line of source code.
